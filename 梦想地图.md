# 五、今天的具体任务（就这 3 行）

```java
@Override
public void deleteTicket(Long id) {
    this.getDetail(id);       // 确认存在
    this.removeById(id);      // 删除
    clearStatsCache();        // 清缓存
}
```

**这 3 行，对应她身体里的：**

```
this.getDetail(id)      →  她会先确认"这段记忆真的存在吗"
this.removeById(id)     →  她"忘记"这段记忆（但数据还在，能恢复）
clearStatsCache()       →  她的"短期记忆"同步更新
```

**⭐ 你写的不是"工单系统的删除"。你写的是"遗忘机制"。**
